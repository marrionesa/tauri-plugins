# Permissions

This folder holds the Tauri ACL permission files for the plugin.

## Files

| File                                | Purpose                                                                                                                                                                                                           |
| ----------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `default.toml`                      | The `[default]` permission set enabled when the plugin is added without explicit capability configuration.                                                                                                        |
| `autogenerated/commands/<cmd>.toml` | Auto-generated by `tauri_plugin::Builder::new(COMMANDS)` in `build.rs`. One file per command name with `allow-<cmd>` and `deny-<cmd>` identifiers. **Do not edit by hand** — they are regenerated on every build. |
| `autogenerated/schemas/schema.json` | JSON schema for the TOML files (also autogenerated).                                                                                                                                                              |

## Adding a new permission set

Create a new TOML file (e.g. `scope.toml`) and reference it from `default.toml`:

```toml
# default.toml
[default]
description = "..."
permissions = ["allow-ping", "scope-read-only"]
```

```toml
# scope-read-only.toml
[[set]]
identifier = "scope-read-only"
description = "Restrict ping to read-only scope."
permissions = ["allow-ping"]
```

## Identifiers

The plugin name passed to `Builder::new("<name>")` becomes the prefix in the
final permission identifier: `<plugin-name>:allow-<cmd>` (e.g.
`template:allow-ping`). Identifiers must follow the Tauri identifier syntax:

- lowercase ASCII letters, digits, hyphens
- no leading/trailing hyphen
- single colon allowed when using a prefix
- ≤ 64 chars in the base name; ≤ 129 chars with prefix

See <https://v2.tauri.app/security/scope/> for the full reference.
